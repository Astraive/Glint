# ADR NNNN: Short decision title

- **Status:** Proposed | Accepted | Superseded
- **Date:** YYYY-MM-DD
- **Ticket:** TICKET-ID (external backlog)

- **Superseded by:** none | ADR NNNN

## Context

What forces, constraints and evidence led to this decision. Link spike reports or test evidence. State what is still unknown.

## Decision

The decision, stated so it can be checked. Say explicitly whether it promotes a `RECOMMENDED` or `RESEARCH REQUIRED` item and on what evidence.

## Consequences

Positive, negative and neutral effects. Follow-up tickets. Which specs, schemas, docs or code must change (list them; all are updated in the same pull request).

## Alternatives considered

Each option with the reason it was not chosen.

## Migration notes

Required for any change to a public contract (manifest/schema, package format, SDK, capabilities, IPC). Describe the version bump, compatibility with existing packages, and how authors or users migrate. Write `None: no public contract changes` if that is the case.
